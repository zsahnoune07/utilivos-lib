# FIB-4 Index

Utilivos plugin: Fibrosis-4 (FIB-4) index from age, AST, ALT, and platelet count, with local validation and optional storage persistence.

## Quick start

```bash
utilivos run
utilivos verify
npm test
utilivos build
```

## Plugin details
- Slug: fib4-calculator
- Entry: tool/index.html
- Icon: tool/assets/icon.png
- Thumbnail: tool/assets/thumb.png
- Screenshots: tool/assets/screenshots/home.png
